# Wedding Invitation v19 — อัปเดตภาพการ์ดหน้า–หลัง

ใช้แพ็กเกจ v18 เป็นฐาน เปลี่ยนเฉพาะภาพการ์ดตามไฟล์ Front(2) และ Back(2) ที่แนบมา
- ทั้ง Landing Page และหน้าหลักใช้การ์ดฉบับใหม่ร่วมกัน
- ขนาด 1480 × 2048 px เท่าเดิม ไม่ครอป ไม่ขยาย ไม่แก้ artwork
- WebP lossless ตรวจพิกเซล RGB เทียบต้นฉบับแล้วตรงกัน
- ชื่อไฟล์ใหม่ card-front-v19.webp และ card-back-v19.webp ป้องกันแคชภาพเก่า
- เก็บ PNG ต้นฉบับล่าสุดใน design-source/invitation/
- คงการเปิด 2.4 วินาที เสียงกระดาษ กรอบ responsive และระบบคืนตำแหน่งหน้าเว็บจาก v18
- ข้อมูลชื่อ สถานที่ กำหนดการ และ Dress Code ด้านหลังตรงกับข้อความอ่านในเว็บเดิม จึงไม่เปลี่ยน config

อัปเดตไฟล์ในโปรเจกต์เดิมแล้ว build ด้วย node tools/build-web.cjs และ deploy ตามเดิม
อ่าน README-INVITATION-v18-TH.md สำหรับการตั้งค่า animation/เสียง โดยชื่อไฟล์ภาพปัจจุบันให้ยึด v19 นี้

ตรวจ local assets และ build; ตรวจภาพ lossless และไฟล์แพ็กเกจ ไม่ได้ทดสอบมือถือจริงในรอบนี้
ระบบบันทึกคำอวยพรลง Sheets / Drive ยังอยู่ระหว่างหารือ ไม่ได้เพิ่มในแพ็กเกจนี้
