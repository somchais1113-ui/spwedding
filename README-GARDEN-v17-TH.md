# Wedding Garden Motion — v17

ต่อยอดจาก SP_Wedding_Landing_Garden_v16.zip โดยคง Mesh Gradient, navigation, typography, RSVP, QR sharing, กำหนดการ และสถานที่เดิม

## สิ่งที่เปลี่ยน
- นก 2 ตัวทั้งมือถือและเดสก์ท็อป ใช้ภาพสีน้ำเดิม แยกปีกด้วย SVG clip และขยับจากข้อต่อ มีจังหวะกระพือสลับร่อน บินคนละจังหวะ
- กรอบสีน้ำในหน้าหลักใช้ภาพเดียวกับ Landing Page ขอบบางลงบนมือถือ เคลื่อนไหวตามการเลื่อนอย่างนุ่มนวลไม่เกิน 9px ไม่ปรับความกว้างหน้าเว็บหรือระบบล็อก scroll
- เพิ่มการเผยเนื้อหาอย่างนุ่มนวลใน Dress Code, หัวข้อคำอวยพร และ Travel Guide ด้วยระบบ animation เดิม
- ปกการ์ดเชิญทั้งใบด้านหน้าและปกในหน้าต่าง ใช้ PS สีขาวพร้อมรายละเอียดดอกไม้สีฟ้าอ่อน ไม่มีข้อความชื่อใต้โลโก้ ไม่ใช้ filter ที่ทำให้รายละเอียดหาย
- หมุดสถานที่จัดงานบนแผนที่ท่องเที่ยวเปลี่ยนจาก SP เป็นหมุดสีแดง โดยยังใช้ลิงก์นำทางจาก config เดิม

## ไฟล์ที่ดูแล
- css/landing-garden.css — กรอบ นก และรูปแบบปกการ์ด
- js/landing-garden.js — การเริ่ม/หยุด motion และการเคลื่อนไหวตาม scroll
- js/motion.js — เพิ่มพื้นที่ที่ใช้ระบบ reveal เดิม
- assets/images/ps-invitation-white.webp — โลโก้ปกใหม่ 960 × 960
- index.html — นกแบบแยกปีก กรอบหน้าหลัก และหมุด

ภาพประกอบไม่มี interaction และไม่บัง touch target; ปิดการเคลื่อนไหวเมื่อตั้ง Reduce Motion และหยุดเมื่อซ่อนแท็บ/หน้าที่เกี่ยวข้อง หยุด requestAnimationFrame เมื่อการเคลื่อนที่เข้าที่แล้ว

## การตรวจสอบ
ผ่าน syntax check, tools/validate.py, build-web.cjs, tests ของ modal 5 รายการ และ garden lifecycle 3 รายการ (สลับหน้า, ระยะเคลื่อนไหวและหยุด loop, ซ่อนแท็บ/Reduce Motion)
ยังไม่ได้ตรวจภาพจริงในเบราว์เซอร์หรือวัด FPS บน iPhone/Samsung เพราะเบราว์เซอร์ตรวจงานไม่สามารถเปิด local preview ในสภาพแวดล้อมนี้ได้

## อัปโหลด
แตก ZIP แล้วใช้ไฟล์ระดับรากในโปรเจกต์ Vercel เดิม โดยเก็บ environment variables เดิมไว้ build ใช้ tools/build-web.cjs เหมือนเวอร์ชันก่อน ไม่มีการ Deploy ขึ้นเว็บจริงจากแพ็กเกจนี้โดยอัตโนมัติ
