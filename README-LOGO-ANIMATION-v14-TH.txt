SP Wedding — อัปเดต v14
ปรับระบบ Animation ของโลโก้ PS ใหม่ทั้งหมด
====================================================================

1. สาเหตุที่ของเดิมดูไม่ลื่นและดูเชย
--------------------------------------------------------------------
1.1 สาเหตุหลักของอาการกระตุก
    v11-v13 ไล่ค่า filter: blur() จาก 7px ลงมาเป็น 0 บนกลุ่ม SVG ที่มี
    mask ขนาดเต็มภาพ เบราว์เซอร์จึงต้อง re-rasterise โลโก้ทั้งตัวใหม่
    ทุกเฟรม ซึ่งเป็นงานหนักบนมือถือ
    การแก้ใน v12 ที่ยืดเวลาจาก 1500ms เป็น 2400ms จึงไม่ช่วย เพราะ
    ปัญหาอยู่ที่ "คุณสมบัติที่นำมาแอนิเมต" ไม่ใช่ที่ "จังหวะเวลา"

1.2 สาเหตุที่ดูเชย
    ทุกชั้น (ตัวอักษร ดอกไม้ ลายเซ็น) ใช้ท่าเดียวกันหมด คือ
    จาง + เลื่อนขึ้น + เบลอ ซึ่งเป็นรูปแบบพื้นฐานที่พบทั่วไป
    ไม่มีลำดับการเล่าเรื่องและไม่มีจุดพีค

1.3 ปัญหาทางเทคนิคอื่นที่พบระหว่างแก้
    - ประกาศ will-change ไว้บน .botanical-logo svg * คือทุก element ลูก
      ทำให้สร้าง compositor layer เกินจำเป็นและค้างไว้ตลอด session
    - กฎ .motion-paused .botanical-logo *{transform:none!important}
      ไปล้าง transform จัดตำแหน่งของ v13 ด้วย ทำให้เมื่อปิด Motion
      หรือเครื่องเปิด reduced motion โลโก้จะกระโดดออกจากตำแหน่งที่จัดไว้
      (แก้แล้วใน v14)


2. แนวคิดใหม่ของ v14
--------------------------------------------------------------------
เปลี่ยนจาก "จางเข้ามา" เป็น "ถูกพิมพ์ลงบนกระดาษ"
และแอนิเมตเฉพาะ transform กับ opacity เท่านั้น ไม่มี filter ใด ๆ

ลำดับของแบบ A (ค่าเริ่มต้น) รวมประมาณ 3.1 วินาที
    1) หมึกไล่ขึ้นจากล่างสู่บนผ่านตัวอักษร PS หลังขอบ mask แบบนุ่ม
    2) ดอกไม้คลี่บานตามจังหวะที่หมึกไล่ไปถึง
    3) ลายเซ็น PHANTIRA & SOMCHAI เขียนจากซ้ายไปขวาเหมือนลายมือ
    4) แสงกวาดแบบฟอยล์ผ่านโลโก้หนึ่งครั้งเป็นจุดปิด

จุดที่ทำให้แสงฟอยล์ดูแพง: ใช้ alpha channel ของไฟล์
assets/images/sp-wedding-logo.png เป็น mask โดยตรง แสงจึงวิ่งเฉพาะ
บนเนื้อหมึก ไม่ล้นออกนอกลาย และไม่ต้องสร้างไฟล์ภาพเพิ่มแม้แต่ไฟล์เดียว


3. ทางเลือก 3 แบบ และวิธีสลับ
--------------------------------------------------------------------
สลับได้ด้วยการแก้ค่าเดียว คือแอตทริบิวต์ data-logo-motion
บน <div id="botanical-logo"> ใน index.html ไม่ต้องแก้ CSS

    A  data-logo-motion="ink"    (ค่าเริ่มต้นที่ตั้งไว้ให้แล้ว)
       หมึกไล่ขึ้น + ดอกไม้คลี่ + ลายเซ็น + แสงฟอยล์
       สมดุลที่สุดระหว่างความน่าสนใจกับความสุภาพ

    B  data-logo-motion="bloom"
       ดอกไม้บานนำก่อน ตัวอักษร PS จึงไล่ขึ้นตาม
       เหมาะเมื่อต้องการอารมณ์เชิงพฤกษศาสตร์ชัดกว่า

    C  data-logo-motion="calm"
       ลำดับเดียวกับ A แต่สั้นลงและตัดแสงฟอยล์ออก
       เรียบและสงบที่สุด เหมาะกับโทนพิธีเช้า

ดูเทียบกันทั้งสามแบบได้ที่ไฟล์ preview-logo-motion.html
หน้านี้เรียก css/celebration.css ไฟล์เดียวกับหน้าจริง จังหวะที่เห็น
จึงตรงกับเว็บที่ deploy ทุกประการ กดปุ่ม "เล่นซ้ำ" เพื่อดูใหม่ได้
ไฟล์นี้ใส่ noindex ไว้แล้ว เป็นเครื่องมือรีวิวภายใน จะลบทิ้งก่อน
deploy จริงก็ได้ ไม่กระทบหน้าเว็บ


4. ไฟล์ที่แก้ไข
--------------------------------------------------------------------
index.html
    เพิ่มชุด mask ใหม่ใน <defs> ได้แก่ sp-rise-letters, sp-rise-flowers,
    sp-sign-wipe, sp-art-alpha และ gradient ที่เกี่ยวข้อง
    เพิ่มกลุ่ม .sp-sheen สำหรับแสงฟอยล์
    ใส่ data-logo-motion="ink" บน #botanical-logo

css/celebration.css
    เขียนบล็อก Monogram motion system ใหม่ทั้งหมดแทนของเดิม
    แก้บั๊กตำแหน่งโลโก้ตอนปิด Motion ตามข้อ 1.3

js/celebration.js
    เพิ่ม safety timeout 2600ms กันโลโก้ค้างซ่อนหากโหลดภาพไม่สำเร็จ
    คืน compositor layer ด้วยคลาส .logo-settled เมื่อจบลำดับ

preview-logo-motion.html
    ไฟล์ใหม่ สำหรับเปรียบเทียบทั้งสามแบบ

README-LOGO-ANIMATION-v14-TH.txt
    ไฟล์นี้


5. สิ่งที่ไม่ได้แตะต้อง
--------------------------------------------------------------------
- ไฟล์ภาพต้นฉบับ sp-wedding-logo.png ไม่ถูกแก้ไขแม้แต่ไบต์เดียว
  ทุกอย่างทำผ่าน SVG mask
- ตำแหน่งและขนาดโลโก้ที่จัดไว้ใน v13 ยังคงเดิมทั้ง desktop และ mobile
- โครงสร้าง Section, RSVP, Google Sheets, Environment Variable
  และ Code.gs ไม่มีการเปลี่ยนแปลง ไม่ต้องแก้อะไรฝั่ง backend


6. ผลการทดสอบ
--------------------------------------------------------------------
ทดสอบด้วย Chromium แบบ headless บนหน้า index.html จริง
- ลำดับ 12 เฟรมตลอด 3.1 วินาที ทำงานครบทุกชั้น ไม่มี JavaScript error
- โหมด prefers-reduced-motion: reduce แสดงโลโก้เต็มรูปทันที ตำแหน่งถูกต้อง
- โหมด motion-paused (ผู้ใช้กดปิด Motion) แสดงโลโก้เต็มรูป ตำแหน่งถูกต้อง
- Mobile viewport 390x844 ตำแหน่งตรงกับโหมดปกติ ไม่มีการกระโดด
- tools/validate.py ผ่าน (PASS)

ข้อจำกัดของการทดสอบ: สภาพแวดล้อมที่ใช้มีเฉพาะ Chromium จึงยังไม่ได้
ทดสอบบน Safari จริง อย่างไรก็ตามเทคนิค mask-type:alpha ที่ใช้
เป็นรูปแบบเดียวกับที่โค้ดเดิมของโปรเจกต์ใช้อยู่แล้ว (mask botanical-growth)
และทำงานได้บนเว็บที่ deploy จริง ความเสี่ยงจึงต่ำ
แนะนำให้เปิดเช็คบน iPhone หนึ่งรอบหลัง deploy


7. ขั้นตอน Deploy
--------------------------------------------------------------------
1) แทนที่ไฟล์เดิมด้วยแพ็กเกจนี้
2) Push ขึ้น GitHub ตามปกติ Vercel จะ deploy อัตโนมัติ
3) Hard refresh แล้วทดสอบทั้ง desktop และ mobile
4) ถ้าต้องการเปลี่ยนเป็นแบบ B หรือ C ให้แก้ค่า data-logo-motion
   ตามข้อ 3 แล้ว push อีกครั้ง

ไม่ต้องแก้ Code.gs และไม่ต้องแก้ Environment Variable
