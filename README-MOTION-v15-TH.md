# Motion update v15

ปรับจาก SP_Wedding_Logo_Animation_v14.zip ที่แนบมาในรอบนี้

- แก้กรอบโลโก้ให้ตรงกับไฟล์ PS จริง 1526 × 1541 ไม่บังคับเป็นสี่เหลี่ยมจัตุรัส
- ยกเลิกการเลื่อนโลโก้ขึ้นด้วยค่าติดลบและการย่อซ้ำซ้อน โลโก้อยู่ในพื้นที่ปกติของหน้า
- ใช้ภาพต้นฉบับร่วมกันสองพื้นที่ที่ไม่ทับกัน: ตราสัญลักษณ์และชื่อ ค่อย ๆ เผยต่อเนื่องโดยเปลี่ยนเฉพาะ opacity; ไม่มีการตัดแยกดอกไม้ด้วยตำแหน่งโลโก้เก่า
- รูปคู่บ่าวสาวใช้ภาพเดียว แทนภาพซ้อนและการเปลี่ยน master ระหว่างทาง ลดการลอยเหลือ 2px / 20 วินาที
- ปิด scroll parallax และ pointer tilt ใน config; คง Mesh Gradient แบบช้า ลดจำนวนชั้นบนมือถือ
- ไม่เปลี่ยน QR, ระบบส่งออกภาพ, RSVP, ลิงก์สถานที่ หรือข้อมูลพิธี
- ภาพต้นฉบับและฟอนต์ทุกไฟล์เหมือนชุดที่แนบมา

เปิด index.html เพื่อดูหน้าเว็บ หรือ preview-logo-motion.html ซึ่งพาไปยังหน้าเดียวกัน
Deploy ใช้กระบวนการ Vercel เดิมพร้อม environment variables เดิม ชุดนี้ยังไม่ได้ deploy ขึ้นเว็บจริง

ผลตรวจ: JavaScript syntax, build, asset references และ regression tests ของ dialogs/RSVP/export จำนวน 16 รายการผ่าน
เบราว์เซอร์ของสภาพแวดล้อมนี้เข้าถึงเซิร์ฟเวอร์ตัวอย่างไม่ได้ จึงยังไม่ได้ตรวจภาพจริงบน Chrome/Safari หรือวัด frame rate บนอุปกรณ์ Galaxy S22
แนะนำตรวจบนมือถือจริงหลัง deploy: หน้าแรก, เข้าเว็บ, เปิด/ปิดการ์ด, หมุนจอ และการตั้งค่า Reduce Motion
