# คู่มือภาพ ฟอนต์ และสี

## ภาพสำหรับรีทัช

| ไฟล์ | ขนาด canvas | การแสดงผล | แนวทางแก้ไข |
| --- | --- | --- | --- |
| `assets/images/hero-couple.png` | 1536 × 1024 px | กว้างประมาณ 850–940 px บน desktop และเต็มความกว้างเนื้อหาบนมือถือ | ซุ้มต้องอยู่ครบ ไม่ตัดยอดซุ้มหรือฐานเสา รักษาพื้นขาวบริเวณขอบ |
| `assets/images/ceremony-chair.png` | 1024 × 1536 px | กว้างสูงสุด 380 px บน desktop / 220 px บนมือถือ | เว้นขอบรอบช่อดอกไม้และขาเก้าอี้ ไม่วางข้อความรวมในภาพ |

ภาพไม่มีการฝังชื่อ วันงาน หรือปุ่ม ข้อความทั้งหมดเป็น HTML จึงแก้ภาษาและวันงานได้โดยไม่ต้องรีทัชภาพใหม่

Workflow แนะนำ:

1. เปิด PNG ใน Photoshop หรือโปรแกรมที่ใช้อยู่ แล้วบันทึก master เป็น PSD แยกไว้กับงานของคุณ
2. หากรีทัชใบหน้าจริง ให้รักษาทิศทางแสง ตำแหน่งศีรษะ และสัดส่วนร่างกายตามต้องการ ภาพปัจจุบันเป็นตัวละครสมมติ
3. รักษา canvas และอัตราส่วนเดิม ใช้ sRGB และขอบพื้นขาว `#FFFFFF`
4. ส่งออกเป็น PNG ชื่อเดิมทับใน `assets/images/` หากใช้ WebP/JPEG ให้เปลี่ยนนามสกุลใน `js/config.js` ให้ตรง
5. ไม่ควรใส่ตัวหนังสือลงในภาพ โดยเฉพาะข้อความที่ต้องอ่านบนมือถือ
6. เก็บภาพต้นฉบับความละเอียดสูงสำหรับแก้ต่อ และส่งออกเวอร์ชันเว็บขนาดเบากว่าเมื่อรีทัชเสร็จ

ถ้าเปลี่ยนสัดส่วนภาพหลัก ให้ปรับ `assets.hero.width/height` ใน config และ `aspect-ratio` ใน `.hero-art img` ภายใน CSS ให้ตรงกัน

ภาพอ้างอิงใน `design-source/figma-reference.png` เป็นภาพบางส่วนที่อ่านจาก Figma ขนาด 607 × 1024 px สำหรับเทียบ direction ไม่ใช่ไฟล์ภาพ master หรือเลเยอร์ต้นฉบับ

## ฟอนต์ที่แนบ

| ไฟล์ | ฟอนต์ | หน้าที่ |
| --- | --- | --- |
| `prompt-regular.ttf` | Prompt Regular | เนื้อหาภาษาไทยและปุ่ม |
| `prompt-medium.ttf` | Prompt Medium | หัวข้อภาษาไทย |
| `wedding-script.otf` | URW Z003 Medium Italic | ชื่อคู่บ่าวสาวและหัวข้อภาษาอังกฤษ |
| `wedding-serif.otf` | URW P052 Roman | ตัวเลขนับถอยหลังและรายละเอียด serif |

ชื่อฟอนต์ใน CSS เป็นชื่อ alias ที่กำหนดผ่าน `@font-face` อย่าเปลี่ยนชื่อไฟล์โดยไม่แก้ path ฟอนต์สคริปต์ใช้กับภาษาอังกฤษเท่านั้น ส่วนภาษาไทยใช้ Prompt เพื่อคงความอ่านง่าย

มีเอกสาร Prompt OFL และเอกสารลิขสิทธิ์/ข้อยกเว้นฟอนต์ URW ในโฟลเดอร์เดียวกัน เก็บเอกสารเหล่านี้ไว้เมื่อส่งต่อแพ็กเกจ ไม่ต้องติดตั้งฟอนต์ลงระบบปฏิบัติการเพื่อเปิดเว็บ แต่ผู้รีทัชข้อความใน Photoshop สามารถติดตั้งฟอนต์จากไฟล์ที่ให้ได้

## สีของเว็บ

แก้ที่ `:root` ใน `css/styles.css`:

| Token | สีปัจจุบัน | ใช้งาน |
| --- | --- | --- |
| `--paper` | `#FFFFFF` | พื้นหลังหลัก |
| `--ink` | `#394333` | ข้อความหลัก |
| `--muted` | `#687160` | ข้อความรอง |
| `--accent` | `#667B4E` | หัวข้อและปุ่มสีเขียว |
| `--accent-dark` | `#4D613A` | ปุ่ม hover และข้อความเน้น |
| `--line` | `#DCE3D5` | เส้นบางและกรอบ |
| `--wash` | `#F4F6F0` | พื้นแผนที่และนับถอยหลัง |

ทิศทางเริ่มต้นเลือกขาว–เขียวให้ตรงอารมณ์ของ Figma หากจะเชื่อมกับโลโก้ SP navy ของงาน เปลี่ยน `--accent` เป็น `#223C5B`, `--accent-dark` เป็น `#172A42`, `--ink` เป็น `#27384C`, `--muted` เป็น `#5E6D7C`, `--line` เป็น `#D8E0E8` และ `--wash` เป็น `#F3F6F9` ภาพสีน้ำยังใช้ภาพเดิมได้

## มุมมอง responsive

- มากกว่า 800 px: กำหนดการและภาพเก้าอี้วางคู่กัน สถานที่แบ่งสองคอลัมน์
- 601–800 px: ลดระยะห่างและขนาดภาพ
- ไม่เกิน 600 px: เนื้อหาเรียงลงแนวตั้ง ปุ่มแตะง่าย แผนที่เต็มคอลัมน์
- เคารพ `prefers-reduced-motion` เมื่อแขกเลือกให้เครื่องลดแอนิเมชัน

ชื่อคู่บ่าวสาว ข้อความเชิญ และทุกปุ่มยังเป็น text จริง กรอบและเส้นเป็น CSS ภาพประกอบเป็น raster สองไฟล์แยกกัน
