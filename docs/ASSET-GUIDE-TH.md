เก็บชื่อไฟล์เดิมและอัตราส่วนเดิมเมื่อรีทัช โลโก้ใช้ PNG โปร่งใสที่เจ้าของงานส่งมาตรง ๆ ภาพประกอบใหม่เป็น JPEG พื้นขาว ไม่มีข้อความหรือ PSD แยกชั้น หน้าเว็บใช้สีธรรมชาติของภาพต้นฉบับ ไม่มีฟิลเตอร์ย้อมฟ้า โลโก้และปุ่มยังเป็น Navy เพื่อเชื่อมธีม

แก้ token หลักใน `css/styles.css` และสีเฉพาะหน้าเปิดใน `css/celebration.css` รวมถึงสีปากกาใน `js/celebration.js` หากเปลี่ยนแบรนด์อีกครั้ง

ฟอนต์ภาษาไทย Prompt และภาษาอังกฤษ WeddingScript / WeddingSerif อยู่ใน `assets/fonts/` พร้อมเอกสารสิทธิ์ใช้งาน ต้องส่งโฟลเดอร์นี้ไปด้วยทุกครั้ง ตัวอย่าง standalone ฝังฟอนต์ไว้แล้ว ไม่ดึง Google Fonts

อัปเดต 1.4: ใช้ภาพ JPEG ที่ผู้ใช้ส่งมาทั้งสองภาพโดยคงไฟล์ต้นฉบับ ไม่ย้อมสีหรือครอป ปรับสัดส่วนแสดงผลตามภาพจริง เอาตัวอักษรสัญลักษณ์หัวใจและลูกศรออก ปุ่มแสดงความยินดีใช้ข้อความ ไม่มีอีโมจิหรืออนุภาคหัวใจ
