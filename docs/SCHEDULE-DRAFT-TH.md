# กำหนดการร่าง — 25 ตุลาคม 2569

เวลา 07:00–12:00 น. ตามเจ้าของงานกำหนด ตารางนี้เป็นข้อเสนอสำหรับงานที่บ้าน ปรับกับครอบครัว หมอสูตรขวัญ และพระสงฆ์ก่อนใช้จริง ไม่ใช่ฤกษ์ที่คำนวณไว้

| เวลา | กิจกรรม |
| --- | --- |
| 07:00–07:45 น. | ทำบุญเช้าเพื่อความเป็นสิริมงคล |
| 07:45–08:00 น. | ต้อนรับแขกและเตรียมขบวนขันหมาก |
| 08:00–08:30 น. | แห่ขันหมากและต้อนรับเจ้าบ่าว |
| 08:30–09:00 น. | พิธีหมั้นและสวมแหวน |
| 09:00–09:45 น. | บายศรีสู่ขวัญคู่บ่าวสาว |
| 09:45–10:30 น. | ผูกแขนและสมมาผู้ใหญ่ |
| 10:30–11:00 น. | ถ่ายภาพและรับคำอวยพร |
| 11:00–12:00 น. | ร่วมรับประทานอาหารและส่งแขก |

## เงื่อนไขที่ใช้วางร่าง

- สมมติว่ามีพิธีสงฆ์ตอน 07:00 น.; หากครอบครัวไม่มีพิธีสงฆ์ เปลี่ยนช่วงนี้เป็นต้อนรับและอาหารเช้าได้
- รวมขันหมาก สินสอด และสวมแหวนไว้ในช่วงเช้า ยืนยันจำนวนประตูและลำดับย่อยกับผู้ใหญ่
- ให้หมอสูตรขวัญยืนยันระยะเวลาบายศรีสู่ขวัญ และธรรมเนียมสมมาของครอบครัว
- 09:45–10:30 เน้นพ่อแม่และญาติผู้ใหญ่ก่อน แขกคนอื่นอวยพรต่อช่วงถ่ายภาพได้ เพื่อไม่ให้ 100 ท่านต้องรอคิวทั้งหมดใน 45 นาที
- จัดทีมอาหารแยกจากทีมพิธี เตรียมพื้นที่ด้านซ้ายให้พร้อมก่อน 11:00 น. เผื่อพิธีช้าเล็กน้อย
- เก็บกำหนดการเป็นร่าง (`scheduleConfirmed: false`) จนกว่าจะยืนยันจริง

หลักการสู่ขวัญและผูกแขนอ้างอิงบทความ “กินดอง” ของกรมศิลปากร: https://www.finearts.go.th/infofa/view/64128-กินดอง เวลาและการจัดช่วงในตารางเป็นข้อเสนอของงานนี้ ไม่ได้มาจากแหล่งอ้างอิง
