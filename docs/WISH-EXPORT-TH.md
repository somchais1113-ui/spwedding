# บันทึกคำอวยพรเป็นภาพ

เลือกพิมพ์หรือเขียนด้วยลายมือ → เลือกขนาดภาพ → บันทึกการ์ดเป็นภาพ → ดาวน์โหลด PNG จากหน้าตัวอย่าง บนมือถือแตะค้างที่ภาพเพื่อบันทึกได้เช่นกัน

| รูปแบบ | ขนาด PNG | เทมเพลตต้นฉบับ |
|---|---|---|
| แนวตั้ง 4:5 | 1080 × 1350 px | assets/templates/wish-portrait.png |
| แนวนอน 16:9 | 1920 × 1080 px | assets/templates/wish-landscape.png |

ภาพแนบจริงเป็น 4:5 และ 16:9 จึงรักษาทั้งสองรูปแบบ ไม่มีการยืดภาพแนวนอนเป็น 9:16 ตัวไฟล์ PNG เทมเพลตคง bytes เดิม ข้อความและลายมือถูกประกอบลงภาพใหม่ด้วย Canvas โดยไม่แก้ไฟล์ต้นฉบับ

ใช้ฟอนต์ Prompt ที่แนบกับเว็บ รอโหลดฟอนต์ก่อนวัดข้อความ ตัดบรรทัดภาษาไทยตามคำ/กลุ่มตัวอักษร รักษาบรรทัดที่แขกพิมพ์มา และลดขนาดอักษรเมื่อข้อความยาว โดยไม่ตัดข้อความทิ้ง หากยาวเกินพื้นที่จริงจะแจ้งให้ลดข้อความแทนการตัดหาย ชื่อผู้เขียนแสดงใต้คำอวยพร ถ้าไม่ใส่ชื่อจะเว้นไว้

ลายมือรักษาสัดส่วนเดิม ไม่ยืดตามสัดส่วนการ์ด ตัวรูปแบบ พื้นที่ข้อความ และตำแหน่งชื่อแก้ได้ใน js/wish-export.js ภาพบันทึกใช้เฉพาะ template ภายในแพ็กเกจ ไม่ได้ใช้ภาพท่องเที่ยวจากเว็บ จึงไม่ติด cross-origin จากภาพสถานที่

การบันทึกภาพไม่ส่งข้อมูลให้บ่าวสาว ปุ่ม “ส่งคำอวยพร” ยังส่งผ่าน /api/wishes ตามคู่มือเดิม ไฟล์ Preview แบบรวมฟอนต์/ภาพรองรับการสร้าง PNG ในเครื่องได้ ส่วน index.html ในโฟลเดอร์ ถ้า browser จำกัด Canvas บน file:// ให้ใช้ Preview หรือเปิดผ่าน Node server ตามคู่มือ

Browser จะให้ผู้ใช้กดดาวน์โหลดหรือบันทึกตามระบบของอุปกรณ์ เว็บไม่สามารถเขียนลงอัลบั้มโดยไม่ผ่านคำสั่งของผู้ใช้ ไม่มีการแสดงว่าบันทึกลง Photos แล้วทั้งที่ยังไม่ได้กด

การตรวจรอบนี้ครอบคลุมกฎตัดคำ/จัดพื้นที่/วันที่/ไฟล์อ้างอิง ยังไม่ได้ทดสอบการเรนเดอร์ Canvas และบันทึกภาพผ่าน browser มือถือจริง
