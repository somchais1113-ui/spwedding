# การ์ดคำอวยพร — ฉบับ 2.2

เลือกพิมพ์หรือเขียนด้วยลายมือ → เลือกรูปแบบ → บันทึกการ์ดเป็นภาพ → แชร์ภาพการ์ด หรือดาวน์โหลด PNG

| รูปแบบ | พิกเซลภาพส่งออก | ขนาดพิมพ์ที่ 300 DPI |
|---|---|---|
| แนวตั้ง 4:5 | 2400 × 3000 | 8 × 10 นิ้ว |
| แนวนอน 16:9 | 3200 × 1800 | ประมาณ 10.67 × 6 นิ้ว |

PNG มี pHYs 11811 pixels/metre หรือประมาณ 299.9994 DPI ตามการปัดค่าเป็นจำนวนเต็มของมาตรฐาน โปรแกรมที่อ่าน metadata จะแสดง 300 DPI ไม่ใช่เพียงการเปลี่ยนชื่อไฟล์ จำนวนพิกเซลข้างต้นคือขนาดจริงของ Canvas ไม่ขึ้นกับ devicePixelRatio

ข้อความคำอวยพร ข้อความลงท้าย และชื่อผู้เขียนใช้ PKF-Rayrai จาก assets/fonts/PKF-rayraiDEMO.ttf ที่ผู้ใช้แนบมา รอโหลดฟอนต์สำเร็จก่อนวัดและวาด หากฟอนต์โหลดไม่สำเร็จจะให้ลองใหม่ ไม่ส่งออกโดยใช้ฟอนต์อื่นเงียบ ๆ Prompt ใช้สำรองเฉพาะอักขระที่ไม่มีในฟอนต์นั้น

จัดข้อความและชื่อชิดซ้าย เว้นกรอบข้อความจากดอกไม้ ชื่ออยู่ในคอลัมน์แคบด้านซ้ายใต้เส้นคั่นบาง ๆ ตัดคำไทยด้วย Intl.Segmenter รักษาบรรทัดที่แขกพิมพ์ ถ้าเนื้อความหรือชื่อยาวเกินพื้นที่จะแจ้งให้ลดข้อความ ไม่ตัดข้อความหายและไม่ปล่อยให้ล้นลงรูป

ตัวพิมพ์ถูกวาดใหม่ที่ความละเอียดปลายทาง ลายมือวาดจากจุดเส้นต้นฉบับเป็นภาพ 2400 px ก่อนประกอบลงการ์ด ภาพเทมเพลตดอกไม้ยังใช้ไฟล์ต้นฉบับที่แนบมาโดยไม่แก้ bytes การเพิ่มพิกเซลส่งออกไม่ได้สร้างรายละเอียดดอกไม้เพิ่มจากต้นฉบับ หากต้องการพิมพ์ภาพประกอบให้คมขึ้น สามารถแทนเทมเพลตด้วยไฟล์ที่ละเอียดกว่าในสัดส่วนเดิม

## Native Share Sheet

เว็บใช้ navigator.share({files:[File]}) ผ่าน Web Share API เพื่อเปิดเมนูแชร์ของระบบบนเบราว์เซอร์ที่รองรับ ต้องเปิดผ่าน HTTPS (หรือ localhost สำหรับพัฒนา) และผ่าน navigator.canShare({files}) ก่อนแสดงปุ่ม File ถูกเตรียมก่อนผู้ใช้กดแชร์เพื่อรักษา user activation

เว็บไม่ได้เรียก UIActivityViewController หรือ Intent.ACTION_SEND โดยตรง เพราะเป็น API ของแอป native รายชื่อแอปที่มีให้เลือกถูกกำหนดโดยระบบและเบราว์เซอร์ ไม่สามารถบังคับให้ทุกแอปในเครื่องแสดงได้ ผู้ใช้ยกเลิกได้ ไม่มีการอ้างว่าส่งถึงผู้รับแล้ว มีปุ่มดาวน์โหลด PNG อยู่เสมอเมื่อเบราว์เซอร์ไม่รองรับหรือแชร์ไม่ได้

แอปปลายทางอาจบีบอัดภาพหรือลบ DPI metadata ถ้าต้องเก็บไฟล์ต้นฉบับสำหรับพิมพ์ให้ดาวน์โหลด PNG หรือแชร์เป็นไฟล์ตามความสามารถของแอปนั้น

การแชร์/ดาวน์โหลดภาพเป็นคนละคำสั่งกับ “ส่งคำอวยพร” ซึ่งใช้ /api/wishes ตามคู่มือ GUESTBOOK-TH.md

## ไฟล์ที่แก้ต่อ

- js/wish-export.js: ขนาดภาพ พื้นที่ข้อความ ชื่อ และ PNG density
- js/celebration.js: การวาดลายมือและ Native Share Sheet
- css/styles.css: @font-face ของ PKF-Rayrai
- assets/templates/wish-portrait.png และ wish-landscape.png: เทมเพลตเดิม

Preview แบบไฟล์เดียวฝังฟอนต์และเทมเพลตไว้แล้ว สำหรับ index.html หาก browser จำกัด Canvas บน file:// ให้ใช้ Preview หรือเปิดผ่านเซิร์ฟเวอร์ตามคู่มือ

ตรวจการเรนเดอร์จริงด้วย Canvas บน Node: โหลดฟอนต์ ขนาดพิกเซล การจัดชิดซ้าย ลายมือ และอ่าน PNG กลับด้วย decoder อิสระได้ครบ ตรวจ CRC ทุก chunk และ metadata 300 DPI แล้ว ยังไม่ได้ทดสอบ UI หรือ Share Sheet บน iOS/Android จริง
