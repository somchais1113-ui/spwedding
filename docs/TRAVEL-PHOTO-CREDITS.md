# เครดิตภาพเที่ยวรอบสังคม

ภาพจริง 16 รายการ: 8 ภาพอยู่ในแพ็กเกจ และ 8 รายการเรียกภาพจากแหล่งออนไลน์ ต้องเชื่อมอินเทอร์เน็ต การดาวน์โหลดบางโดเมนถูกยกเลิกโดยระบบเครือข่าย จึงยังไม่อ้างว่าทุกภาพเปิดออฟไลน์ได้ ภาพออนไลน์ตรวจความสัมพันธ์กับโพสต์ต้นทางแล้ว แต่ยังไม่ได้ตรวจ pixels หรือการแสดงผลผ่าน browser ในรอบนี้

## ภาพกิจกรรม

Camping ใช้ภาพสนามหญ้าของ Move Camp โดยระบุภาพตามจริง; คีรีวงกตเป็นภาพอาคารโฮมสเตย์; รถอีแต๊กใช้ภาพจากโพสต์กิจกรรมเฉพาะ; จุดชมวิวแม่น้ำโขงใช้ภาพสถานที่เดียวกับวัดผาตากเสื้อ; ATV ใช้ภาพปกวิดีโอที่ระบุ ATV นางิ้ว เอิงเอยโดยตรง ไม่มีภาพของผู้ให้บริการชื่อคล้ายกัน

ดู URLs ภาพและบันทึกการตรวจใน assets/travel/locations/photo-sources.json ภาพออนไลน์ไม่ได้ฝังใน HTML ตัวอย่าง ต้องเชื่อมอินเทอร์เน็ต หากต้นทางไม่โหลดจะยังมีลิงก์แหล่งภาพให้เปิดและปุ่มนำทางใช้งานได้
