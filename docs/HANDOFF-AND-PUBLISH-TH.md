# ส่งต่องานและขึ้นเว็บไซต์

แพ็กเกจนี้เป็น HTML/CSS/JavaScript ไม่มี framework หน้าเปิดใช้โลโก้ SP สี navy และวันงาน 25 ตุลาคม 2569 ภาพประกอบแนวสีน้ำตามทิศทาง Figma เดิม ฟอนต์แนบไว้ทั้งหมด

## ส่งต่อ Claude / AI

ให้แก้จากไฟล์เดิมในแพ็กเกจ รักษา `js/config.js` เป็นแหล่งข้อมูลหลัก เวลา 07:00–12:00 น. เป็นร่างที่ผู้ใช้กำหนด หมุดบ้านใช้ลิงก์ Maps ที่ผู้ใช้ส่งแล้ว ห้ามเดาที่อยู่เป็นข้อความ รักษา tokens และ @font-face ในเครื่อง คงโหมดพิมพ์/ลายมือ ดาวน์โหลด PNG และ reduced motion ห้ามอ้างว่าส่งคำอวยพรแล้วหากไม่ได้รับ `saved: true` จากเซิร์ฟเวอร์

## Static hosting

อัปโหลด `index.html`, `css/`, `js/`, `assets/` เท่านั้น คำอวยพรจะบันทึกในอุปกรณ์แขกและดาวน์โหลดเป็นการ์ด ไม่มีข้อมูลส่วนกลางจนกว่าจะเปิดใช้ API

## Node hosting

อ่าน `GUESTBOOK-TH.md` และรัน `node server.mjs` ตั้ง HOST/PORT ตามผู้ให้บริการ ใช้ HTTPS และ persistent disk สำหรับ WISHES_DATA_DIR การติดตั้ง Node server ในโฮสต์ต้องทำแยกจากการอัปโหลด HTML ไม่มีการเผยแพร่เว็บในงานส่งมอบนี้

## ตรวจหลังแก้

รัน `python3 tools/validate.py` จากโฟลเดอร์แพ็กเกจ ตรวจบนมือถือเรื่องการเปิดหน้า การนับเวลาไทย การลากนิ้วบน canvas การหมุนหน้าจอ การสลับแท็บ การดาวน์โหลด PNG และข้อความยืนยันส่งจริงจากโฮสต์ก่อนส่งลิงก์ให้แขก
