# การขึ้นเว็บและส่งต่องาน

## เปิดในเครื่อง

แตก ZIP ก่อน แล้วดับเบิลคลิก `index.html` ไม่ต้องรัน build และไม่ต้องเชื่อมอินเทอร์เน็ตเพื่อโหลดภาพหรือฟอนต์ ปุ่ม Google Maps, โทรศัพท์, RSVP และการแชร์ไปแอปอื่นต้องใช้ความสามารถของอุปกรณ์และลิงก์จริง

## ไฟล์ที่อัปโหลดขึ้นโฮสต์

ใช้ `index.html`, `css/`, `js/` และ `assets/` ที่ระดับรากของแพ็กเกจเดียวกัน ไฟล์ `docs/`, `tools/`, `design-source/`, `START-HERE.html` และ README เป็นเอกสารทำงาน ไม่จำเป็นต้องเผยแพร่ให้แขก

แพ็กเกจนี้ไม่ใช้ API, secret, npm dependency หรือฐานข้อมูล โฮสต์ static ที่เสิร์ฟไฟล์ HTML ได้สามารถใช้งานได้ หากใช้ Vercel / GitHub ให้นำชุดไฟล์เว็บไซต์เข้าระบบที่คุณใช้อยู่ โดย root ต้องมี `index.html` และไม่ต้องสั่ง build framework

ยังไม่มีเว็บไซต์ออนไลน์จากแพ็กเกจนี้ และยังไม่มีลิงก์สำหรับส่งแขก ต้องอัปโหลดไปยังโดเมน/โฮสต์ของคุณก่อน

## หลังอัปโหลด

1. เปิด URL จริงบนมือถือ แล้วลองดูหัวข้อ สถานที่ และกำหนดการ
2. เติม `siteUrl` ใน `js/config.js` เป็น URL จริงแบบ HTTPS แล้วอัปโหลดไฟล์ config ฉบับใหม่
3. ลองเปิดหมุดด้วยมือถือจริงหนึ่งครั้ง ให้แน่ใจว่าจุดหมายตรงประตูบ้าน ไม่ใช่ใจกลางจังหวัด
4. ลองไฟล์ปฏิทิน โดยตรวจวันและเวลาในแอปปฏิทินก่อนส่งให้แขก
5. ถ้ามีฟอร์ม RSVP ให้ส่งคำตอบทดสอบที่ฟอร์มนั้นและตรวจข้อมูลปลายทาง

## ลิงก์ชื่อแขก

ใส่ `?to=` ต่อท้าย URL ตามด้วยชื่อแขก ลิงก์ที่มีชื่อจะเปลี่ยนข้อความเฉพาะส่วนการ์ด ตัวอย่างโครงสร้าง:

`https://your-domain.example/?to=คุณสมชาย`

สามารถใช้ JavaScript `encodeURIComponent('ชื่อแขก')` เมื่อสร้างลิงก์อัตโนมัติ ฟังก์ชันแชร์ของเว็บไซต์จะส่งลิงก์คำเชิญทั่วไปโดยตัดชื่อแขกออก

## บรีฟส่งต่อ Claude / AI / Developer

คัดลอกข้อความต่อไปนี้พร้อมส่ง ZIP ที่แตกแล้ว:

> โปรดแก้ไขเว็บไซต์งานแต่งงานในแพ็กเกจนี้ โดยคง HTML/CSS/Vanilla JavaScript ที่เปิด index.html ในเครื่องได้ อ่าน README-TH.md, docs/ASSET-GUIDE-TH.md และ js/config.js ก่อนเริ่มงาน รักษาสไตล์ watercolor wedding ขาว–เขียว พื้นที่โปร่ง ภาพประกอบใหญ่ และข้อความไทยที่อ่านง่าย ใช้ฟอนต์ local ใน assets/fonts และ design tokens ใน css/styles.css ข้อมูลชื่อ วัน เวลา พิกัด ผู้ติดต่อ และรูปภาพควรแก้ผ่าน config ห้ามสร้างวันงาน หมุด ที่อยู่ หรือหมายเลขโทรศัพท์ขึ้นเอง ห้ามเปลี่ยนลูกเล่นหัวใจให้แสดงยอดรวมแขกหรือบันทึกสำเร็จ หากยังไม่มี backend จริง ภาพ hero-couple.png ขนาด 1536×1024 และ ceremony-chair.png ขนาด 1024×1536 เป็นจุดสลับภาพรีทัช ตรวจการทำงานของคำเชิญเฉพาะบุคคลผ่าน ?to=, การเปิดและปิดการ์ด, นับถอยหลัง, ปฏิทินเขตเวลาไทย, การนำทาง, การแชร์, คีย์บอร์ด และ reduced motion หลังแก้ ตรวจทุก relative path และส่งแพ็กเกจที่เปิดได้จริงกลับมาพร้อมรายการไฟล์ที่แก้

## ขยายระบบในภายหลัง

หากต้องการเก็บ RSVP หรือข้อความอวยพรไว้ส่วนกลาง ควรเพิ่ม backend หรือใช้ฟอร์มจริง ปุ่มหัวใจในเวอร์ชันนี้เป็นเอฟเฟกต์เฉพาะหน้าจอ ไม่ได้เป็นข้อมูล guestbook หรือระบบตอบรับ การเชื่อมบริการเพิ่มในภายหลังควรแยกจากเว็บไซต์เดิมให้ชัดและทดสอบการรับข้อมูลก่อนใช้งานจริง
