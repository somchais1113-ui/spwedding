# Motion Edition — เวอร์ชัน 1.1

ทิศทาง: การเคลื่อนไหวช้า เบา และมีพื้นที่ให้ภาพสีน้ำได้หายใจ ภาพต้นฉบับ ชื่อไฟล์ ขนาด และข้อมูลเว็บไซต์ยังคงเดิม ไม่ต้องรีทัชใหม่เพื่อใช้เวอร์ชันนี้

| บริเวณ | การเคลื่อนไหว | จังหวะ |

ภาพยังเป็น PNG แบนหนึ่งชั้น จึงเคลื่อนทั้งภาพ ไม่ได้แยกคน ดอกไม้ หรือใบไม้ให้ขยับอิสระ ข้อความและปุ่มเป็นองค์ประกอบ HTML แยกต่างหาก

## ปรับค่าที่เดียว

เปิด `js/config.js` แล้วแก้ส่วน `motion`:

```js
motion: {
  enabled: true,
  intensity: 0.65,
  ambient: true,
  scroll: true,
  pointer: true,
  revealDuration: 1500
}
```

| ค่า | ผล |
| --- | --- |
| `enabled` | `false` เพื่อปิดเอฟเฟกต์ทั้งชุด |
| `intensity` | 0–1 คุมระยะลอย เลื่อน และเอียง แนะนำ 0.4–0.65 เพื่อคงความนุ่มนวล |
| `ambient` | ปิด/เปิดการลอยช้าของภาพ |
| `scroll` | ปิด/เปิดมิติขณะเลื่อนหน้า |
| `pointer` | ปิด/เปิดการตอบสนองเมาส์ ใช้เฉพาะอุปกรณ์ที่มีเมาส์และ hover |
| `revealDuration` | ระยะเวลาเปิดภาพ หน่วยมิลลิวินาที จำกัด 500–2500 |

ค่า `intensity: 0` จะหยุดระยะเคลื่อนภาพ แต่ยังคงการปรากฏเนื้อหาและเปิดการ์ด ถ้าต้องการภาพนิ่งทั้งหมด ใช้ `enabled: false`

จังหวะอื่น ๆ อยู่ใน `css/motion.css` ส่วนการจัดการ viewport และการเคลื่อนตามเมาส์อยู่ใน `js/motion.js` ไม่ใช้ GSAP หรือ dependency เพิ่ม ทุกอย่างทำงานจากไฟล์ในเครื่องได้

## มือถือและการพักภาพ

- เมนูด้านบนมีปุ่ม “พักภาพ” / “เล่นภาพ” และจำตัวเลือกไว้เฉพาะเบราว์เซอร์ของแขกคนนั้น ถ้าอุปกรณ์ไม่อนุญาต local storage ปุ่มยังทำงานในครั้งที่เปิดอยู่
- เมื่ออุปกรณ์เปิด Reduce Motion เว็บไซต์จะปิดเอฟเฟกต์โดยอัตโนมัติ
- บนมือถือ ลดระยะ parallax และไม่ใช้การเอียงตามนิ้ว จึงเลื่อนหน้าได้ตามปกติ
- การลอยแบบวนจะพักเมื่อภาพออกนอกหน้าจอหรือสลับไปแท็บอื่น
- การทำงานตามเมาส์ประมวลผลเฉพาะตอนเคลื่อนเมาส์และช่วงที่ภาพค่อย ๆ คืนตำแหน่ง ไม่มีลูป JavaScript ที่รันต่อเนื่องเมื่อภาพนิ่ง
- เนื้อหามีอยู่และมองเห็นได้แม้เอฟเฟกต์ไม่ทำงาน ไม่ต้องรอแอนิเมชันจบจึงกดนำทางได้
- เมื่อใช้คีย์บอร์ดเข้าถึงปุ่มที่กำลังปรากฏ จะแสดงปุ่มนั้นเต็มทันที

## ส่งงานต่อ

ถ้ารีทัชภาพแล้ว บันทึกทับ PNG ชื่อเดิมได้ทันที เอฟเฟกต์ยังทำงานโดยไม่ต้องแก้ motion code

เวลาส่งให้ AI หรือ developer กรุณาคง wrapper ของภาพทั้งสี่ชั้น (`art-scroll`, `art-tilt`, `art-drift`, `art-entrance`) เพราะแต่ละชั้นรับผิดชอบ transform คนละแบบ การรวมทุก transform ไว้บน `<img>` ชั้นเดียวอาจทำให้เอฟเฟกต์ทับกัน

เพิ่มในบรีฟเดิม: “คงจังหวะ slow watercolor motion, การพักภาพ, prefers-reduced-motion และการพักเมื่อออกนอก viewport ไม่เพิ่มเอฟเฟกต์เร็วหรือการเคลื่อนไหวรบกวนข้อความโดยไม่ได้รับโจทย์เพิ่ม”

## การตรวจในรอบนี้

ตรวจ syntax ของ JavaScript, อ้างอิงไฟล์ HTML/CSS, ลิงก์ภายในหน้า, การรวม motion ใน HTML ไฟล์เดียว, ความครบถ้วนของ ZIP และ byte identity ของภาพเทียบเวอร์ชันเดิม ไม่มีการทดสอบแสดงผลผ่านเบราว์เซอร์ในรอบนี้
