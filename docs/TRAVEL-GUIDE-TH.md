# Explore Around Us — เที่ยวรอบสังคม

เพิ่มในเวอร์ชัน 1.8.0 หลังส่วนสถานที่จัดงาน ก่อนการ์ดเชิญ โดยรักษา Header, Navigation, ฟอนต์ Orange Avenue / Prompt, สี และส่วนอื่นของเว็บเดิม

## โครงสร้างที่แก้ไขแยกได้

- `js/travel/locations.js`: เนื้อหาสถานที่ หมวดหมู่ เส้นทาง ไฟล์ภาพและแหล่งอ้างอิง ทั้งหมดอยู่ไฟล์เดียว
- `js/travel/travel-helpers.js`: ตัวกรอง URL การนำทาง พิกัดบนภาพ และกฎควบคุมแผนที่ เป็นฟังก์ชันที่ทดสอบแยกได้
- `js/travel/travel.js`: ตัวควบคุมหมุด แผนที่ การลาก/ซูม รายละเอียด และ animation
- `css/travel/travel.css`: CSS จำกัดขอบเขตใน `.travel-guide` / `.travel-sheet` ใช้ design tokens เดิม
- `assets/travel/map/`: ภาพจำลองสังคม 1536 × 1024 px อัตราส่วน 3:2
- `assets/travel/characters/`: คู่บ่าวสาวกับรถ พื้นหลังโปร่งใส 1536 × 1024 px
- `assets/travel/locations/`: ช่องภาพรายสถานที่ 1200 × 800 px อัตราส่วน 3:2
- `assets/travel/icons/`: คู่มือชุดไอคอน SVG ที่แสดงผ่านโค้ด
- `design-source/travel/`: PNG ต้นฉบับความละเอียดเต็มสำหรับรีทัช ภาพที่เว็บโหลดเป็น WebP

## พฤติกรรม

เลือกทั้งหมด / สายบุญ / คาเฟ่ / Adventure / ธรรมชาติ โดยไม่เปลี่ยนหน้า หมุดนอกหมวดจะจางลง และหมุดจุดพักที่อยู่ในเส้นทางแนะนำยังเลือกได้ แม้เป็นอีกหมวด เช่น คาเฟ่ท้ายทริปไหว้พระ

Desktop ตั้งแต่ 901 px ใช้ map/panel ประมาณ 70/30 ส่วนมือถือใช้ native modal bottom sheet มีปุ่มปิด ปิดด้วย Escape หรือแตะนอก sheet และคืน focus ให้จุดที่เลือก การ์ดมีปุ่มนำทางขนาดใหญ่ ติดด้านล่าง sheet

แผนที่ใช้ภาพ 2.5D + SVG route + DOM buttons ไม่มี WebGL, Three.js, SDK แผนที่ หรือ dependency ใหม่ ลากพื้นหลังด้วยนิ้ว/เมาส์ ซูมด้วยสองนิ้วหรือปุ่ม +/− และปุ่มพอดี มือถือเริ่มซูมเล็กน้อยเพื่อให้หมุดไม่แน่นเกินไป ใช้รายชื่อทั้งหมดด้านล่างแทนแผนที่ได้

Keyboard: Tab ไปยังตัวกรอง/หมุด/รายชื่อ, Enter หรือ Space เลือก; เมื่อ focus อยู่ที่พื้นแผนที่ ใช้ลูกศรเลื่อน และ +/− ซูม

เส้นทางวาดประมาณ 5.4 วินาที ตัวละครเดินทาง 6.4 วินาทีต่อครั้ง มีปุ่มเล่นซ้ำ ไม่วนไม่สิ้นสุด หยุดเมื่อแผนที่พ้นจอ/เปลี่ยนแท็บ รองรับ `prefers-reduced-motion` และปุ่มพักภาพเดิม

## เพิ่มหรือแก้สถานที่

คัดลอก object ใน `locations` แล้วเปลี่ยน `id` ให้ไม่ซ้ำ กำหนด `number`, ชื่อ, `category` เป็น array ของ mode IDs, เนื้อหา, คำแนะนำ และแหล่งข้อมูล

`mapPosition: {x, y}` เป็นตำแหน่งบนภาพจำลองขนาด 1000 × 667 ไม่ใช่พิกัดภูมิศาสตร์ เว้นขอบภาพและระยะห่างของหมุดพอให้กดง่าย

`coordinates: {lat, lng}` ใช้เฉพาะพิกัดจริงที่ตรวจยืนยันแล้ว มิฉะนั้นใช้ `null` และตั้ง `mapsQuery` เป็นชื่อสถานที่พร้อมอำเภอ/จังหวัด Google Maps จะค้นหาปลายทางจากข้อความนี้

`distance` หน่วยกิโลเมตร และ `estimatedTravelTime` หน่วยนาที ต้องเป็นค่าที่ตรวจเส้นทางขับรถจากสถานที่จัดงานแล้วเท่านั้น ค่า `null` จะแสดงให้ตรวจใน Maps แทน ไม่มีการเอาระยะเส้นตรงมาคิดเป็นเวลาเดินทาง

ปุ่มนำทางใช้ตำแหน่งปัจจุบันของแขกเป็นจุดเริ่มต้น หากต้องการวางแผนจากบ้านจัดงาน แขกตั้งจุดเริ่มต้นใน Google Maps ได้ พิกัดบ้านจากลิงก์สั้นยังไม่สามารถยืนยันได้ในการจัดทำฉบับนี้

`googleMapsURL` มีไว้เป็นข้อมูล/ลิงก์สำรอง แต่ตัวสร้างปุ่มจะให้ความสำคัญกับ `coordinates` หรือ `mapsQuery` เพื่อได้ Directions URL ที่ถูกต้อง เปิดด้วย `target="_blank"` และ `rel="noopener noreferrer"`

กิจกรรมรถอีแต๊กใช้ `parentDestinationId: "khiri-wongkot"` และ camping อ้างอิง Move Camp ไม่ได้สร้างหมุดผู้ให้บริการสมมติ จุดชมวิวโขงใช้บริเวณวัดผาตากเสื้อ พิกัดคีรีวงกตเป็นหมู่บ้าน ต้องนัดจุดขึ้นรถกับผู้ให้บริการ

## ใส่ภาพจริง

1. ดูชื่อไฟล์และขนาดใน `assets/travel/locations/slots.json`
2. วางภาพที่สิทธิ์ใช้งานครบลงโฟลเดอร์นั้น เช่น `wat-pa-phu-kon.webp` ขนาด 1200 × 800 px
3. เปลี่ยน `images[0].src` จาก `null` เป็นค่าเดียวกับ `images[0].slot` และแก้ `alt` ให้บอกภาพจริง

ตอนนี้แสดง placeholder ที่ระบุชัดว่ากำลังเตรียมภาพ ไม่ใช้ภาพสร้างแทนภาพถ่ายของสถานที่จริง ไม่มีคำขอรูปที่ไม่มีไฟล์ และเมื่อภาพเสียจะกลับเป็น placeholder อัตโนมัติ ภาพใหม่รองรับ local assets; ไม่มีการดึงภาพจาก URL ภายนอกโดยไม่ตั้งใจ

## แก้เส้นทาง

แต่ละ object ใน `routes` ผูกกับ mode ID และมี `stops` เป็น location IDs เรียงลำดับ แก้ title/subtitle/note ได้ในไฟล์เดียว เป็นไอเดียการเที่ยว ไม่ใช่ GPS หรือผลคำนวณเส้นทางจริง หากต้องการเพิ่มหมวด ให้เพิ่ม `modes`, route ของหมวดนั้น และ category ในสถานที่

ทริปเช้าชมทะเลหมอกแนะนำวันก่อนหรือหลังงาน เพื่อไม่ชนพิธี 07:00 น. วัดป่าภูก้อนและคีรีวงกตอยู่เขตนายูง อุดรธานี จึงระบุพื้นที่และแยกแนะนำเป็นอีกทริป ไม่อ้างว่าทุกแห่งอยู่ใกล้บ้านจัดงาน

## ขอบเขตข้อมูลและการตรวจ

ข้อมูลรายสถานที่มี sources และวันที่ตรวจ 8 กันยายน 2569 คำแนะนำช่วงเวลาเป็นข้อเสนอสำหรับจัดทริป ไม่ใช่เวลาเปิดที่รับประกัน ไม่มีราคา/รอบกิจกรรมที่สร้างขึ้นเอง ตรวจวันเปิด ผู้ให้บริการ และสภาพเส้นทางก่อนเดินทาง

ทดสอบด้วย `node --test tools/test-travel.cjs` ครอบคลุมสถานที่ทั้ง 16 รายการ ตัวกรอง ความสัมพันธ์ route URL ปลอดภัย พิกัด/ค่าที่ยังไม่ทราบ และขอบเขตการลาก/ซูม รวมถึง `python3 tools/validate.py` ตรวจไฟล์อ้างอิงและ anchor

ยังไม่ได้ทดสอบการแสดงผลและสัมผัสจริงผ่าน browser/device ในรอบนี้ ควรตรวจใน Safari iPhone และ Chrome Android ก่อนเปิดให้แขกใช้ โดยเฉพาะ pinch, bottom sheet, เปิด Maps และเปลี่ยนแนวจอ ส่วนการส่งคำอวยพรยังต้องรันผ่าน backend ตามคู่มือเดิม HTML แบบไฟล์เดียวเป็นตัวอย่างและไม่แกล้งแสดงว่าส่งสำเร็จ
