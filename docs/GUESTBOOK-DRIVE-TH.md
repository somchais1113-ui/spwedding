# เก็บคำอวยพรเป็นภาพการ์ดใน Google Drive

สำหรับเว็บที่วางบน GitHub Pages หรือโฮสต์แบบไฟล์นิ่ง ซึ่งไม่มีเซิร์ฟเวอร์รับ `POST /api/wishes`

## หลักการทำงาน

เมื่อแขกกด **ส่งคำอวยพร** เว็บจะจัดข้อความหรือลายมือลงบนเทมเพลตการ์ดใบเดียวกับที่ใช้ในปุ่ม
"มาแชร์ความทรงจำกันเถอะ" แล้วส่งภาพนั้นไปเก็บใน Google Drive ผ่าน Google Apps Script
ผลลัพธ์ในโฟลเดอร์คือไฟล์ภาพการ์ดที่เปิดดูได้ทันที ไม่ใช่ข้อความดิบ

| หัวข้อ | ค่า |
|---|---|
| ขนาดภาพที่อัปโหลด | 1200 × 1500 px (ตั้งค่าได้) |
| ขนาดไฟล์โดยประมาณ | 300 ถึง 350 KB ต่อคำอวยพร (JPEG) |
| ชื่อไฟล์ | `wish-20261025-093012-ชื่อแขก.jpg` |
| ค่าใช้จ่าย | ไม่มี ใช้โควตา Google ปกติ |

ภาพ 300 DPI ความละเอียดเต็มยังดาวน์โหลดได้จากปุ่มเดิมของแขกตามปกติ ไม่กระทบกัน

## ขั้นตอนติดตั้ง 6 ขั้น

**1. สร้างที่เก็บใน Google Drive**

สร้างโฟลเดอร์ใหม่ ตั้งชื่อเช่น `คำอวยพรงานแต่ง SP` แล้วคัดลอก `FOLDER_ID` จาก URL

```
https://drive.google.com/drive/folders/1AbCdEfGhIjKlMnOpQrStUvWxYz
                                        └──────── FOLDER_ID ────────┘
```

ถ้าต้องการสารบัญที่ค้นหาได้ ให้สร้าง Google Sheet เปล่าเพิ่มอีกหนึ่งไฟล์ แล้วคัดลอก `SHEET_ID`
จาก URL ในลักษณะเดียวกัน ข้อนี้ไม่บังคับ

**2. สร้างโปรเจกต์ Apps Script**

เปิด https://script.google.com แล้วกด **New project** ลบโค้ดตัวอย่างทิ้ง
วางเนื้อหาทั้งหมดจาก `tools/google-apps-script/Code.gs` ลงไปแทน

**3. เติมค่า 3 บรรทัดบนสุดของ Code.gs**

```js
var FOLDER_ID = '1AbCdEfGhIjKlMnOpQrStUvWxYz';
var SHEET_ID = '';                    // เว้นว่างได้
var SHARED_TOKEN = 'sp-wedding-2569'; // ตั้งข้อความอะไรก็ได้
```

กด Run ที่ฟังก์ชัน `testConfiguration` หนึ่งครั้งเพื่ออนุญาตสิทธิ์และตรวจว่า ID ถูกต้อง
ครั้งแรก Google จะเตือนว่าแอปยังไม่ผ่านการตรวจสอบ ให้กด Advanced แล้ว Go to project

**4. Deploy เป็น Web app**

กด **Deploy → New deployment → เลือกชนิด Web app** แล้วตั้งค่าให้ตรงตามนี้

| ช่อง | ต้องเลือก |
|---|---|
| Execute as | **Me** (บัญชีเจ้าของ Drive) |
| Who has access | **Anyone** |

คัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`

> ต้องเป็น `Anyone` เท่านั้น ถ้าเลือก `Anyone with Google account` แขกที่ไม่ได้ล็อกอิน Google
> บนมือถือจะส่งไม่ได้ และจะเห็นข้อความ "ยังส่งไม่สำเร็จ"

**5. ใส่ค่าลงใน `js/config.js`**

```js
  wishes: {
    endpoint: 'https://script.google.com/macros/s/AKfycb.../exec',
    token: 'sp-wedding-2569',   // ต้องตรงกับ SHARED_TOKEN
    archiveFormat: 'portrait',
    archiveLongEdge: 1500,
    archiveFileType: 'jpeg'
  },
```

**6. อัปโหลดขึ้น GitHub Pages แล้วทดสอบส่งจริงหนึ่งครั้ง**

เมื่อสำเร็จ ปุ่มจะเปลี่ยนเป็น "ส่งคำอวยพรแล้ว" และมีไฟล์ภาพใหม่ในโฟลเดอร์ Drive ทันที

## ทุกครั้งที่แก้ Code.gs ต้อง Deploy ใหม่

Apps Script ไม่ได้ใช้โค้ดล่าสุดอัตโนมัติ ต้องกด **Deploy → Manage deployments → ไอคอนดินสอ →
Version: New version → Deploy** ทุกครั้ง มิฉะนั้นเว็บจะยังคุยกับโค้ดเวอร์ชันเก่า

## ข้อจำกัดที่ควรทราบก่อนวันงาน

- **`token` มองเห็นได้จากหน้าเว็บ** เพราะอยู่ในไฟล์ JavaScript ฝั่งผู้ใช้ มันกันบอตทั่วไปได้
  แต่กันคนที่ตั้งใจไม่ได้ ถ้าเจอสแปม ให้เปลี่ยน `SHARED_TOKEN` แล้ว Deploy ใหม่ พร้อมแก้ `config.js`
- **ต้องเปิดผ่านลิงก์เว็บไซต์เท่านั้น** ถ้าเปิดไฟล์ `index.html` จากเครื่องโดยตรง เบราว์เซอร์จะห้าม
  อ่านภาพเทมเพลตลงบน canvas ทำให้สร้างการ์ดไม่ได้ เว็บจะแจ้งเตือนตามจริง ไม่แกล้งบอกว่าส่งสำเร็จ
- **แต่ละคำอวยพรใช้เวลาส่ง 3 ถึง 8 วินาที** บนเน็ตมือถือ เพราะต้องอัปโหลดภาพ ปุ่มจะแสดงสถานะกำลังส่ง
  ตลอดช่วงนั้น ลดเวลาได้โดยลด `archiveLongEdge` เหลือ 1200 หรือ 1000
- **โควตา Apps Script** บัญชี Google ทั่วไปรองรับราว 20,000 คำขอต่อวัน เพียงพอสำหรับงานแต่งงาน

## ถ้ายังส่งไม่สำเร็จ ให้ไล่ตรวจตามลำดับนี้

1. เปิด Web app URL ที่ลงท้าย `/exec` ในเบราว์เซอร์ตรง ๆ ต้องเห็น
   `{"service":"sp-wedding-guestbook-drive-v1","ready":true}` ถ้า `ready` เป็น `false` แปลว่ายังไม่ได้ใส่ `FOLDER_ID`
2. เปิด Developer Tools แท็บ Network ดูคำขอไปยัง `script.google.com`
   - ขึ้น CORS error แปลว่า Who has access ยังไม่ใช่ `Anyone`
   - ขึ้น 401 หรือ 403 แปลว่ายังไม่ได้ Deploy เวอร์ชันใหม่
3. ใน Apps Script เปิดเมนู **Executions** ดูว่าคำขอเข้ามาถึงหรือไม่ และ error คืออะไร
4. ตรวจว่า `token` ใน `config.js` ตรงกับ `SHARED_TOKEN` ใน `Code.gs` แบบตัวอักษรต่อตัวอักษร

## ถ้าเลิกใช้ Google Drive

ลบค่า `endpoint` ใน `js/config.js` ให้เป็นสตริงว่าง เว็บจะกลับไปใช้ `POST /api/wishes`
ของ `server.mjs` เหมือนเดิมทันที ไม่ต้องแก้โค้ดส่วนอื่น
