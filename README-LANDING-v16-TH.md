# Landing Garden v16

ต่อยอดจาก v15 ที่อนุมัติ เพิ่มเฉพาะฉากตกแต่งในหน้า Landing

- ดอกไม้สีน้ำฟ้า-น้ำเงินรอบขอบจอ ไหวเบา ๆ พร้อมฉากทะเลสาบด้านล่าง
- นกบินบริเวณขอบหน้าเป็นช่วง ๆ 2 ตัวบนมือถือ / สูงสุด 3 เส้นทางบนจอใหญ่
- พื้น Mesh Gradient, โลโก้, ฟอนต์, ปุ่ม, ข้อความ และหน้าหลักทั้งหมดคงเดิม
- รูปตกแต่งไม่รับการคลิกและซ่อนจาก screen reader
- พักเมื่อสลับแท็บหรือออกจากหน้า Landing; Reduce Motion แสดงฉากนิ่งและซ่อนนก
- ภาพเพิ่มประมาณ 215 KB โหลดแบบความสำคัญต่ำและใช้ซ้ำ ไม่เพิ่มไลบรารี

เปิด index.html หลังแตก ZIP ทั้งชุด หรือใช้กระบวนการ deploy Vercel เดิม
แก้จังหวะ/ความเข้ม/ขนาดได้ใน css/landing-garden.css และ lifecycle ใน js/landing-garden.js

ตรวจแล้ว: build, JavaScript syntax, ไฟล์อ้างอิง, การคงเนื้อหาเดิมแบบเทียบตรง และ regression เปิด/ปิด dialog 5 รายการผ่าน
ยังไม่ได้วัด FPS หรือทดสอบภาพบนมือถือจริง และยังไม่ได้ deploy เว็บจริง
