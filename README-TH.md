# Somchai & Phantira — Wedding HTML Package

เว็บคำเชิญงานแต่งงานแนวสีน้ำ ขาว–เขียว ตามทิศทาง Figma ที่คุณส่งมา ใช้ HTML, CSS และ JavaScript แบบธรรมดา ไม่มี framework และไม่ต้องติดตั้ง Node.js เพื่อเปิดใช้งาน

## เริ่มใน 3 ขั้นตอน

1. แตก ZIP ทั้งโฟลเดอร์ก่อน อย่าเปิด HTML จากใน ZIP โดยตรง
2. เปิด `index.html` ใน Chrome, Safari, Edge หรือ Firefox รุ่นปัจจุบัน
3. แก้ข้อมูลใน `js/config.js` แล้วบันทึกและรีเฟรชหน้าเว็บ

โฟลเดอร์แพ็กเกจนี้เปิดจากไฟล์ในเครื่องได้ ภาพและฟอนต์ทั้งหมดอยู่ในแพ็กเกจ เมื่อพร้อมส่งลิงก์ให้แขก ให้อัปโหลดไฟล์เว็บไซต์ขึ้นโฮสต์ก่อน

## จุดที่ต้องเติมก่อนส่งให้แขก

| ข้อมูล | แก้ใน `js/config.js` | สถานะที่ส่งมอบ |
| --- | --- | --- |
| ชื่อคู่บ่าวสาว | `couple` | Somchai / Phantira / SP |
| วันและเวลาเริ่มงาน | `date.startAt` | ว่าง รอข้อมูลจริง |
| วันและเวลาจบงาน | `date.endAt` | ว่าง รอข้อมูลจริง |
| ข้อความช่วงเวลางาน | `date.timeLabel` | งานเช้า จบไม่เกินเที่ยง |
| ชื่อสถานที่และที่อยู่ | `venue.name`, `venue.address` | บ้านของเรา / ที่อยู่ยังว่าง |
| หมุด Google Maps | `venue.mapUrl` | ว่าง ไม่มีหมุดสมมติ |
| กำหนดการและเวลา | `schedule`, `scheduleConfirmed` | ลำดับกิจกรรมเสนอเบื้องต้น |
| ที่จอดรถ | `venue.parking` | รอรายละเอียด |
| ผู้ติดต่อ | `contact` | ว่าง ปุ่มโทรซ่อนอยู่ |
| ลิงก์เว็บไซต์จริง | `siteUrl` | ว่าง ใช้เมื่ออัปโหลดแล้ว |

วันที่ใช้รูปแบบ `YYYY-MM-DDTHH:mm:ss+07:00` โดยแทน YYYY, MM, DD, HH, mm, ss ด้วยตัวเลขวันและเวลาจริงในประเทศไทย ต้องมีเขตเวลา `+07:00` อย่าใช้ปี พ.ศ. ในค่าที่เครื่องอ่าน ส่วนหน้าเว็บแสดงวันเดือนปีภาษาไทยอัตโนมัติ

เมื่อตั้งวันเริ่มที่ถูกต้อง นาฬิกานับถอยหลังจะแสดงเอง เมื่อตั้งเวลาจบที่อยู่หลังเวลาเริ่มด้วย ปุ่มดาวน์โหลดปฏิทินจึงแสดง หากไม่มีวันจริง เว็บแสดงข้อความรอประกาศ

## สิ่งที่ทำได้แล้ว

- หน้าเดียวที่ปรับสำหรับมือถือ แท็บเล็ต และคอมพิวเตอร์
- ปุ่มกระโดดไปสถานที่และกำหนดการ
- เปิดอ่านการ์ดเชิญ พร้อมปิดด้วยปุ่ม ×, ปุ่ม Escape หรือแตะพื้นที่นอกการ์ด
- คำเชิญระบุชื่อแขกผ่าน `?to=` เช่น `https://your-domain.example/?to=สมชาย` — URL นี้เป็นตัวอย่างโครงสร้างเท่านั้น
- กดหัวใจให้เกิดแอนิเมชัน เป็นลูกเล่นบนหน้าจอของแขกแต่ละคน ไม่ส่งข้อมูลหรือสะสมยอดส่วนกลาง
- นับถอยหลังตามเวลาไทย พร้อมสถานะเมื่อถึงและผ่านวันงาน
- ดาวน์โหลด `.ics` เพื่อเพิ่มวันงานลงปฏิทิน เมื่อกรอกวันเริ่มและสิ้นสุดแล้ว
- เปิดแผนที่ คัดลอกที่อยู่ และโทรผู้ติดต่อเมื่อมีข้อมูลจริง
- แชร์คำเชิญด้วยเมนูแชร์ของอุปกรณ์ หรือคัดลอกลิงก์สำรองเมื่อเว็บไซต์ออนไลน์
- รองรับการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์และการใช้งานด้วยคีย์บอร์ด
- ฟอนต์แนบในเครื่อง ไม่ดึงจาก Google Fonts หรือ CDN

## ภาพและการรีทัช

ภาพใช้งานแยกอยู่ใน `assets/images/` เป็น PNG ไม่มีข้อความในภาพ:

| ชื่อไฟล์ | ขนาดจริง | สัดส่วน | ใช้ที่ไหน |
| --- | --- | --- | --- |
| `hero-couple.png` | 1536 × 1024 px | 3:2 | ภาพเปิดหน้าเว็บ คู่บ่าวสาวใต้ซุ้ม |
| `ceremony-chair.png` | 1024 × 1536 px | 2:3 | ภาพเก้าอี้ดอกไม้ข้างกำหนดการ |

รีทัชแล้วบันทึกทับชื่อเดิมเพื่อให้เว็บอ่านภาพใหม่ทันที ถ้าเปลี่ยนชื่อไฟล์ ให้แก้ `assets` ใน `js/config.js` ด้วย คู่มือขนาด ระยะปลอดภัย ฟอนต์ และสีอยู่ใน `docs/ASSET-GUIDE-TH.md`

ภาพทั้งสองสร้างใหม่ให้ใกล้สไตล์อ้างอิง ไม่ใช่เลเยอร์ภาพต้นฉบับจาก Figma และไม่ได้ใช้ใบหน้าจริงของคู่บ่าวสาว เป็น PNG พื้นขาวที่มีรายละเอียดทั้งหมดรวมในชั้นเดียว ไม่มีไฟล์ PSD แบบแยกเลเยอร์ ภาพอ้างอิงบางส่วนที่ดูจาก Figma และคำสั่งสร้างภาพแนบใน `design-source/`

## โครงสร้างแพ็กเกจ

| ไฟล์ / โฟลเดอร์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บจริงและโครงสร้างเนื้อหา |
| `css/styles.css` | รูปแบบหน้า สี ฟอนต์ responsive และ motion |
| `js/config.js` | ข้อมูลที่เจ้าของงานแก้เป็นหลัก |
| `js/app.js` | การทำงานของหน้าเว็บและปุ่ม |
| `js/helpers.js` | วันที่ ลิงก์ นับถอยหลัง และไฟล์ปฏิทิน |
| `assets/images/` | ภาพ PNG ที่แก้ต่อได้ |
| `assets/fonts/` | ฟอนต์พร้อมเอกสารสิทธิ์ใช้งาน |
| `docs/` | คู่มือแก้ไข คู่มือขึ้นเว็บ และบรีฟส่งต่อ AI |
| `design-source/` | ภาพอ้างอิงจาก Figma และ prompt สร้างภาพ |
| `tools/validate.py` | ตรวจไฟล์ภายในแพ็กเกจโดยไม่ต้องติดตั้ง dependency |
| `asset-manifest.json` | รายการไฟล์ภาพและฟอนต์พร้อมขนาด |
| `START-HERE.html` | คู่มือเริ่มต้นฉบับเปิดด้วยเบราว์เซอร์ |

ไฟล์ `SP-Wedding-Preview.html` ที่ส่งแยกเป็นสำเนารวมทุกอย่างในไฟล์เดียวสำหรับดูตัวอย่าง การแก้จริงควรแก้ไฟล์ในแพ็กเกจ ซึ่งจะไม่ซิงก์กลับไปยังสำเนาตัวอย่างโดยอัตโนมัติ

## ขอบเขตระบบ

นี่เป็นเว็บไซต์ static ไม่ใช้ฐานข้อมูล ไม่มีระบบรับอวยพรส่วนกลางหรือระบบจัดการแขก ปุ่มหัวใจไม่บันทึกข้อมูล หากต้องการรับ RSVP ตอนนี้ ให้ใส่ URL ของฟอร์มที่ใช้งานได้จริงใน `rsvpUrl` แล้วปุ่มตอบรับจะปรากฏ หน้าเว็บจะเปิดไปยังฟอร์มนั้น ไม่มีการอ้างว่ารับคำตอบสำเร็จในเว็บนี้

## ผลตรวจสอบ

ตรวจไวยากรณ์ JavaScript, ไฟล์อ้างอิง HTML/CSS, ขนาดภาพ, ขอบเขตวันที่, ปีอธิกสุรทิน, การแปลงเวลาไทย, ขอบเขตนับถอยหลัง, URL และการตัดบรรทัด UTF-8 ของไฟล์ปฏิทินแล้ว ตรวจ ZIP ว่าแตกได้และได้ไฟล์ครบแล้ว ไม่มีการทดสอบหน้าจอผ่านเบราว์เซอร์ในรอบนี้
